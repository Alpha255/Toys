# Toys

## KeyOverlay — 桌面输入字符置顶显示小玩具

一个常驻桌面顶层的小悬浮窗，显示你**当前按下的单个按键**（每次按键替换上一个，不累积历史）。窗口**鼠标完全穿透**、**不抢焦点**，可以边打字边看效果。

### 功能

- **置顶 + 鼠标穿透**：`WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`，任何程序中打字都能捕获（`WH_KEYBOARD_LL` 全局钩子），窗口永不遮挡鼠标操作。
- **两种风格**
  - `高清`：GDI+ 矢量字形 + 可选投影，平滑抗锯齿
  - `点阵`：把字形栅格化成低分辨率点阵，再逐点亮成"像素灯珠"
- **两种配色**
  - `纯色`：内置 8 种预设色
  - `渐变`：6 种预设渐变，方向可水平 / 垂直
- **大小可调**：点阵调整灯珠尺寸，高清调整字号；超出屏幕宽度会自动缩小。
- **位置可调**：默认显示在**右侧居中**，可选顶部 / 底部 / 左侧居中，距屏幕边缘的边距可调。
- **其他**：透明度、半透明背景板、约 2.4 秒无输入自动淡出、设置自动保存到 `KeyOverlay.ini`、单实例运行。

### 构建

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
# 产物： build\Release\KeyOverlay.exe
```

要求：Windows 10 1703+（用到 `SetProcessDpiAwarenessContext`），MSVC 或 MinGW-w64，CMake 3.16+。

### 快捷键（全局）

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Alt+↑` / `↓` | 放大 / 缩小 |
| `Ctrl+Alt+S` | 切换 高清 / 点阵 |
| `Ctrl+Alt+C` | 下一套配色 |
| `Ctrl+Alt+H` | 暂停 / 恢复捕获 |
| `Ctrl+Alt+X` | 清空当前文字 |
| `Ctrl+Alt+Q` | 退出 |

### 托盘菜单

右键（或左键）点击托盘图标：样式与填充、颜色、大小、透明度、显示（背景板 / 屏幕位置 / 边距）、暂停捕获、快捷键帮助、退出。

### 交互细节

- **所有按键都会显示**：字符键显示字符；`Space` `Esc` `Tab` `Shift` `Ctrl` `Alt` `Win` `Caps` `Enter` `Backspace` `Del` `Ins` `Home` `End` `PgUp` `PgDn` `F1`~`F24` 等显示对应的按键名称，方向键显示 `←` `→` `↑` `↓`
- `Ctrl+字母` 显示为对应字母本身
- 无输入约 2.4 秒后淡出并清空，下一轮打字重新开始
